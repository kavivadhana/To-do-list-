# 📝 Todo List

A simple and responsive **Todo List web application** built to practice JavaScript fundamentals and DOM manipulation.

---

## ✨ Features

* ➕ **Add new tasks** smoothly
* ✅ **Mark tasks as completed** to stay on track
* 🗑️ **Delete tasks** when they are no longer needed
* 📱 **Responsive interface** that looks great on mobile and desktop
* ⚡ **Interactive management** handled completely via vanilla JavaScript

---

## 🛠️ Technologies Used

* **HTML5** – Web page structure
* **CSS3** – Styling and fluid responsive design
* **JavaScript (ES6)** – Core functionality and DOM manipulation

---



---

## 🚀 How to Run

Follow these quick steps to get the project running locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kavivadhana/To-do-list-.git
   ```

2. **Navigate into the project folder:**
   ```bash
   cd To-do-list-
   ```

3. **Launch the application:**
   Open the `sam.html` file directly in any modern web browser.
